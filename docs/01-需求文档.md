# 学科小程序 · 需求文档（首期：语文 / 文言文搜索）

版本 0.1 · 2026-10-05 · 状态：待确认

## 1. 背景与目标

已有一份整理好的数据：初中 100 篇课外文言文，815 句原文与现代文对译，121 个重点字词、578 处例句，以及「现代文 → 文言」反查表（见 `data/文言文字词数据.json`）。目前它只是一个本地网页。

目标是把它做成微信小程序并正式上线：

- 学生看到一个文言字词，能马上查到它的全部义项、每个义项的原句、现代文翻译和出处。
- 反过来，输入一个现代文说法，能查到文言里怎么表达。
- 小程序按科目组织（数学、语文、英语、物理、化学），首期只开放语文里的「文言文搜索」，其余科目显示为「即将上线」。

## 2. 用户与场景

| 用户 | 场景 | 需要什么 |
|---|---|---|
| 初中生 | 做文言文阅读题时遇到不确定的字 | 输入一个字，几秒内看到义项和例句 |
| 初中生 | 考前复习一字多义 | 按字浏览导图，把不熟的字加入生词本 |
| 初中生 | 想知道「离开」「如果」在文言里怎么说 | 输入现代文，看到对应的文言字和例句 |
| 家长 / 老师 | 陪读、出题 | 按篇目看原文对译，隐藏译文让孩子自测 |

## 3. 首期范围

**做：**

1. 微信登录（静默）
2. 科目首页
3. 文言文搜索（双向）
4. 字词详情（一字多义导图）
5. 100 篇原文阅读
6. 收藏 / 生词本
7. 搜索历史
8. 我的（资料、隐私说明、关于）

**不做：** 其他四个科目的内容、诗词、练习题与打分、付费、分享海报、用户评论、管理后台（数据用脚本导入）。

## 4. 功能需求与验收标准

### 4.1 登录

- 打开小程序即静默登录：`wx.login` 取 code，服务端换 openid，签发登录凭证。全程无弹窗。
- 不登录也能浏览和搜索。只有生词本、搜索历史需要登录态；静默登录失败时这两处提示「登录失败，点此重试」。
- 头像和昵称由用户在「我的」里自愿填写，不填不影响任何功能。

验收：清除缓存后首次进入，无任何授权弹窗；收藏一个字，杀掉小程序重进，收藏仍在。

### 4.2 首页（当前科目的功能页）

第一屏直接是当前科目的内容，不再是一页科目选择。

- **科目切换条**：顶部横排语文、数学、英语、物理、化学。当前科目高亮；未上线的置灰，点击提示「正在准备中」。小程序记住上次停留的科目，下次打开直接进入。
- **科目内搜索框**：在当前科目的所有模块里搜索。
- **模块卡片**：每个模块一张，写明里面有什么。语文首期只有「文言文」可用；「古诗词」「阅读理解」「名著导读」置灰标「即将上线」。以后每上线一个模块，只是把对应卡片点亮。
- **继续学习**：上次读到的篇目，以及最近查过的字词（最多 8 个）。没有记录时不显示。

验收：首次打开停在语文；第一屏不用任何点击就能看到搜索框和文言文卡片；切到别的科目再退出重进，仍停在上次的科目。

### 4.3 搜索（首期只有文言文内容）

- 两个入口：首页的科目内搜索框（搜语文下所有模块），以及文言文模块页里的搜索框（只搜文言文）。两者用同一个结果页。
- 结果页顶部有模块筛选：全部、文言文、古诗词、阅读理解……只有一个模块上线时，筛选条仍显示，未上线的模块不可点。
- 文言文模块页：搜索框、热门字（按出现次数取前 12 个：为、使、过、及、归、若、去、故、尽、还、取、卒）、三个入口（100 篇原文、通假字·活用·异义、现代文→文言对照表）。
- 输入即搜，停止输入 300ms 后发起请求。文言文的结果分四组，各组显示条数：
  1. **重点字词**：字头包含关键词。显示字、义项概要、出现次数。
  2. **现代文 → 文言**：义项或释义包含关键词。显示文言字、匹配的义项、一条例句。
  3. **原文句子**：原文包含关键词。显示原句、译文、出处。
  4. **译文句子**：译文包含关键词。显示译文、对应原句、出处。
- 关键词在结果中高亮。每组默认显示前 5 条，可展开全部。
- 无结果时提示换更短的词，并给出热门字。
- 每次点进结果，记入搜索历史。

验收：搜「遗」→ 字词组出现「遗」，4 个义项、9 处例句；搜「离开」→ 现代文组出现「去」；搜「路不拾遗」→ 原文句子组出现第 19、58、72 篇的句子。

### 4.4 字词详情（一字多义导图）

- 顶部：大字、出现次数、义项数、收藏按钮。
- 导图：字为根，每个义项一个分支（一种颜色），带词性、读音和识别提示（如「为＋官职」）。义项按例句数量从多到少排。
- 每个义项下列出全部例句：原句（该字带着重号）、现代文翻译、此处的具体译法、出处。义项超过 4 条例句时默认折叠，显示「展开其余 N 条」。
- 点出处进入原文阅读，并定位、高亮到那一句。
- 长按或点例句右侧按钮，可把这一句加入生词本。

验收：「为」显示 8 个义项共 32 处例句；点任一出处，原文页滚动到对应句并高亮。

### 4.5 原文阅读

- 篇目列表：100 篇，显示序号、篇名、出处，可按篇名筛选。
- 阅读页：一句原文、一句译文交替排列。加点字带着重号，点击弹出半屏释义卡（字、此处意思、所属义项，按钮：看导图、加入生词本）。
- 右上角开关「隐藏译文」，用于自测；隐藏后点某句可单独显示它的译文。
- 篇末列出本篇全部加点字及意思，以及原书注释。
- 底部上一篇 / 下一篇。

### 4.6 生词本

- 两个分组：字词、句子。按加入时间倒序。
- 字词项点击进字词详情；句子项点击进原文并定位。
- 左滑删除，删除后给 3 秒撤销。
- 空状态：说明如何添加，并给一个「去搜索」按钮。

### 4.7 搜索历史

- 在「我的」里查看，最多保留最近 100 条，可单条删除或清空。

### 4.8 我的

- 头像昵称（可选填写）、生词本数量、搜索历史、隐私说明、关于（数据来源说明、版本号）。

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 搜索速度 | 服务端处理 < 100ms，用户感知 < 300ms（4G 网络） |
| 包体积 | 主包 < 1.5MB，总包 < 4MB；语文模块独立分包 |
| 弱网 | 请求超时 8 秒，给出重试按钮，不白屏 |
| 可扩展 | 数据与接口按「科目 → 模块」两级组织。科目和模块的清单（名称、说明、是否上线）由服务端下发，新增模块只需加数据、接口和分包，首页不用改 |
| 安全 | 全程 HTTPS；AppSecret 和签名密钥只存服务器；接口限流（单用户每分钟 120 次） |
| 隐私 | 只收集 openid、用户自愿填写的头像昵称、收藏与搜索记录；提供隐私说明页 |

## 6. 上线前提与风险

1. **域名备案是硬卡点。** 小程序正式版只能请求已备案的 HTTPS 域名。备案期间用开发者工具关闭域名校验做联调，开发不受影响，但发布要等备案通过。
2. **小程序自身也要备案。** 在微信后台单独办理，个人主体同样需要，通过后才能发布。
3. **个人主体的限制。** 可选服务类目较少，不能接支付，不能有用户发布内容。首版是纯查询工具，不涉及这些。具体可选的教育类目以微信后台显示为准，提审前确认。
4. **不能强制登录。** 微信审核要求用户先体验后登录，所以采用静默登录，不弹授权框。
5. **内容版权（需要你决定）。** 文言原文是公版内容，但译文和字词释义来自一本教辅的参考答案。公开上线有被投诉下架的风险。三个选择：
   - 仅自用或小范围使用，不做推广；
   - 上线前把译文和释义改写一遍（可以由我来做，再由老师抽查）；
   - 联系出版方取得授权。
6. **隐私合规。** 需要在微信后台填写《用户隐私保护指引》，小程序内提供隐私说明页。

## 7. 后续扩展（不在首期）

- 语文：古诗词（文件夹里已有《八年级上册古诗文背诵默写手册》）、课内外阅读理解、名著导读（已有 14 本的资料）。每个模块上线时：首页点亮一张卡片，搜索结果多一个模块分组，生词本和历史自动覆盖。
- 文言文：按字词出题自测、错题进生词本、学习进度。
- 其他科目：每个科目一个分包，数据各自一组表，共用登录、生词本、历史三套基础能力。

## 8. 需要你提供

- 小程序 AppID。
- AppSecret：由你自己写入服务器的 `.env` 文件，不要发在对话里。
- 本机安装微信开发者工具并用管理员微信登录。
- 对第 6 节第 5 条（内容版权）的决定。
