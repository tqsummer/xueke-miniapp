# 英语账号隔离与同步（代码完成，尚未部署）

## 使用范围
只有微信云模式启用；H5/普通HTTP模式仍明确显示“本地体验模式”，并没有伪装成微信登录。语文功能、集合和存储不变。

### 隔离
云函数通过 getWXContext().OPENID 取得可信身份。英语独立 english_progress 集合；客户端不传也不能选择 owner/openid。返回哈希账号标识仅用于分区缓存，绝非授权凭据。每次进入英语页面先清可见数据、联网验证身份后再读本账号缓存。验证失败不展示上一个使用者记录。

### 离线与冲突
同一已确认身份的页面可断网练习，答案先存本机。当前题是可改判草稿，下一题/结束/离开时成为连续编号事件。重新联网自动重试，也可点击“立即同步”。设备ID+连续seq去重，服务器ack后清队列；重试不重复计数。并发设备由数据库事务串行合并，复习状态按服务端接收顺序处理，事件时间不会倒退或超前服务器。不是按客户端最后上传的整份快照覆盖。

因离线无法可靠确认是否换了微信账号，**重新进入必须先联网确认身份**。关闭页面前答案草稿已持久化，下次验证同账号后恢复排队。清缓存可能丢失未同步答案；须同步后才能跨设备看到。待同步上限5000条、账号最多100设备，达到限制将明确阻止继续保存而非丢记录。

### 旧记录迁移
旧 english-day12-progress-v1 未标用户，绝不自动上传。用户确认全部属于本人后，先在本机写入账号归属及稳定importId，再发送导入。失败仅同账号可重试，不重复计数；另一账号不能再导入同份旧记录。只填云端不存在的词/方向，不覆盖已有进度。原始旧记录不删除。没有新增删除所有学习记录或自动清缓存功能。

### 权限边界
代码隔离不能代替数据库权限。必须为 **english_progress** 配置客户端 read=false、write=false，仅云函数管理员SDK访问。示例在 cloud/english-permissions.example.json，不能覆盖其他集合权限。当前没有检查或修改真实云环境权限，也没有部署。

## 体验和上线前操作
新小程序产物：miniapp/dist/english-account/cloud。该目录同时包含 cloudfunctions/api（构建时已拷贝语文内容数据）。旧dist/cloud和english-60产物未覆盖。

1. 使用现有AppID、现有云环境导入新目录；核对该环境确是预期测试环境。
2. 在云数据库创建 english_progress 集合（代码也尝试创建），立即设置仅管理端可读写规则。不要使用“所有用户可读”。
3. 右键 cloudfunctions/api → 上传并部署，选择云端安装依赖，保留原函数名 api 和现有环境。使用支持当前SDK的 Node.js 运行时（建议18或更高）。此次只更新函数代码，不创建付费资源或改套餐。
4. 编译小程序；进入英语应显示账号后8位与同步状态。若旧api未更新，会提示无法确认身份，不应绕过为匿名云记录。
5. 完成下方验收后再上传体验版/发布，切勿直接认定生产可用。

本助手没有执行上述部署/权限/发布步骤。上传部署会替换现有api云函数，应先备份/保留现有版本，选择测试环境验证，特别回归语文。

## 必须真实环境验收
- A账号答题→同步→同账号第二设备看到相同进度。
- B账号看不到A记录；切回A仍在；断网且无法验证新账号时不得展示旧账号缓存。
- 已登录页面断网答题，恢复网络仅计一次；在上传成功但响应丢失后重试仍仅一次。
- 两设备同时答同词、队列乱序重发，进度不覆盖/不重复。
- 旧本地记录确认导入，重试不重复，已有云进度不覆盖，B不能导入A已认领旧记录。
- 从客户端SDK直接读取/写入 english_progress 被数据库权限拒绝。
- 首次无状态文档创建、事务并发、网络超时、存储满提示。
- 语文入口、收藏和历史仍正常；音频首次分包下载正常。
