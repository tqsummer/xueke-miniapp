# 英语 Day 1–2 本地练习 MVP

内容参考用户提供的两份 PDF 第 1 页（Day 1、Day 2），PDF 元数据时间为 2019-06-21，未确认属于现行上海官方考纲。66 个合并词条：Day 1 为 33 个，Day 2 为 33 个（包括未编号 along）。

来源快照见 data/english-day1-2-source.json，包含 PDF SHA-256、页码和原始表格。可追溯词条见 miniapp/src/pkg-english/words.ts。多词性按词合并，不按 PDF 行号机械匹配。中文提示表 act 有名词“行动”，英文表未列，本版合并；all 多种词性合并；Day 2 along 原文漏编号。advice 的原音标疑似错误，本版统一暂不展示资料音标。中文释义进行了标点规范及少量易理解表达/同义答案补充，来源原文保留。资料覆盖不等于授权公共再分发，未经确认不上传公开词库。

## 功能

首页现有英语科目内的独立模块入口，不依赖后端 subjects 加载或登录，不影响原文言文功能。Day 1、Day 2 或合并范围，乱序双向默写；中文接受一个已列释义，未命中可人工确认等价释义。英文忽略大小写和多余空格，少数短语允许模板变体。提交只计一次；中文自纠正撤回当次误判后重记，不叠加一次错题。错题按练习方向分别存储，答对移出当前错词列表，历史错误次数保留。答错 10 分钟后复习，答对连续 1/3/7/14/30 天调度。到期列表不混入从未学过的词。四道补充语法题非 PDF 内容，不记录语法复习。

## 持久化与限制

使用 uni.setStorageSync，键 english-day12-progress-v1。只存本机，不按后端用户同步，清缓存或换设备会丢失。有复制 JSON 备份按钮，但暂无导入界面。损坏数据不静默覆盖，提示后允许临时练习。实际保存失败会显示警告。本地词库无需数据库迁移，不修改云函数和自有服务器。

H5 和微信小程序使用 uni.createInnerAudioContext 播放本地 MP3。66 段音频约 489 KB，来自本机 Microsoft Zira Desktop（en-US）合成语音，非真人发音，不调用第三方接口。清单见 data/english-audio-manifest.json。原资料没有词根和语法库，后续需独立补充。语法题为本版编写。
