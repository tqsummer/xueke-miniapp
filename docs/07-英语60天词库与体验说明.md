# 英语 60 天词库

## 本版内容
- 共 1,966 个学习条目（含短语、跨日重复词及明确标注的补录），覆盖提供的两份 PDF Day 1–60。
- 中文→英文、英文→中文、错词再练和到期复习沿用现有功能；60 天选择器可按天或全部练习。
- 原 Day 1–2 的 66 条数据与 ID 完整保留，存储键仍为 `english-day12-progress-v1`，不会为了改名丢失旧进度。
- 语文页面、语文逻辑和存储未改；英语独立 `pkg-english`。

## 来源与质量边界
两份资料各 30 页，PDF 元数据为 2019 年。**不是已经核实的当前上海官方完整中考考纲**，也不代表高考词库。原始表保存在 `data/english-full-source.json`，校验值与缺项说明在 `english-full-provenance.json`。

两表行数、顺序、多词性拆分不同，按词义对齐而非逐行配对。多词性合并，反义组合（at first/last、less/more than、turn up/down 等）拆分，避免反义也能答对。保留原文行号/词头等可追溯信息。`data/english-full-review.json` 汇总各词说明。

hall、mirror、short、weight 是中文表有而英文表缺的明确词义补录，均显式标“待核对补录”。rock/火箭、toll/工具等冲突不当成正确配对；保留英文并注明补充释义。不能唯一还原的中文孤立行列入来源报告，不猜测后塞给相邻词。

英文不区分大小写；中文接受已列同义词，未穷尽自然表达，仍可查看标准释义后手动确认。原资料音标有错，未展示。词根、系统词形训练和更多语法题尚未增加（语法仍为原 4 道补充题）。

## 发音与包体积
使用本机 Microsoft Zira Desktop 美式合成语音，非真人录音。离线生成 24kbps MP3，10 个独立音频分包，每包 6 天。微信首次播放需下载相应分包，缓存后可离线播放。不使用外部 TTS 服务。

`tools/generate-english-audio.ps1` 从五份审核数据合并生成，按清单比较文本更新缓存；`tools/check-english-audio.py` 校验并解码；`tools/check-english-packages.py <构建目录>` 校验实际微信输出各包小于 2MiB、总小于 20MiB。原主包 66 条旧音频暂保留但新界面不再引用。

## 数据维护
```
python tools/build-english-words.py
node miniapp/test/english-core.test.cjs
powershell -File tools/generate-english-audio.ps1
python tools/check-english-audio.py
```
词库拆为有类型的小批次以避免 TypeScript 大联合类型上限。

## 微信开发者工具体验
最终云模式独立产物目录：
`miniapp/dist/english-60/cloud`

从微信开发者工具导入此目录，编译后 首页→英语→词汇背默。不要把仓库根目录或 `miniapp/src` 当成微信运行目录。
旧 `dist/cloud` 未覆盖。仅在开发者工具点“编译”不会把 uni-app 源码重新编译成微信文件。

在 `miniapp` 中重新构建：
```
.\node_modules\.bin\uni.cmd build -p mp-weixin --mode cloud --outDir dist/english-60/cloud
npm run build:h5 -- --outDir dist/english-60/h5
```

## 用户隔离与上线限制
**英语记录仍仅在本机，未新增服务端账号隔离或跨设备同步。** 同设备/同存储空间切换使用者可能共用英语记录；清缓存可能丢失。生产多用户隔离需另外接入后端可信身份与用户级存储，不能将本版当作已完成的多用户云服务。

构建测试不等于真机验收。本次未上传或发布微信版本，仍需开发者工具/真机验证首次分包下载、音频播放及真实账号流程。
