# 上线清单

按顺序做。标「你」的需要你本人操作，标「我」的可以由 Claude 在你确认后执行。

> 备案期间先走云开发方案上线，步骤见《05-云开发方案与迁移》。本清单的第二、三节是备案通过后迁到自有服务器时用的。

## 一、现在就能做（不依赖备案）

- [ ] 你：在微信公众平台拿到小程序 AppID，填进 `miniapp/src/manifest.json` 的 `mp-weixin.appid`（现在是测试用的 `touristappid`）。
- [ ] 你：决定内容版权怎么处理（见需求文档 6.5）。
- [ ] 你：提交域名 `iopenai.tech` 的 ICP 备案；备案期间不要给域名加解析。
- [ ] 你：在微信后台提交小程序备案，可以和域名备案同时进行。
- [ ] 本地联调：
  1. `cd server && npm install && npm run dev`（首次启动自动导入数据，监听 3000 端口）
  2. `cd miniapp && npm install && npm run dev:mp-weixin`
  3. 微信开发者工具导入目录 `miniapp/dist/dev/mp-weixin`，在「详情 › 本地设置」勾选「不校验合法域名」

## 二、域名备案通过后

- [ ] 你：给 `api.iopenai.tech` 加 A 记录，指向 `8.153.38.159`。
- [ ] 你：在阿里云申请 `api.iopenai.tech` 的免费 SSL 证书，下载 Nginx 格式。
- [ ] 你：阿里云安全组放行 80 和 443。
- [ ] 我：服务器安装 Docker 与 Compose 插件。
- [ ] 我：把代码传到服务器；证书放到 `deploy/certs/`，命名为 `api.iopenai.tech.pem` 和 `api.iopenai.tech.key`。
- [ ] 你：在服务器上创建 `deploy/.env`（照 `deploy/.env.example` 填），其中 AppSecret 只写在这里。
- [ ] 我：`docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build`
- [ ] 我：验证 `https://api.iopenai.tech/health` 返回 `{"ok":true}`，`/wenyan/hot` 有数据。

## 三、微信后台

- [ ] 你：开发管理 › 服务器域名 › request 合法域名，添加 `https://api.iopenai.tech`。
- [ ] 你：选择服务类目（教育类下个人主体可选的那一项，以后台显示为准）。
- [ ] 你：填写《用户隐私保护指引》：收集 openid、昵称（自愿）、收藏与搜索记录；用途是保存个人生词本。
- [ ] 你：确认小程序备案已通过。

## 四、发布

- [ ] 我：`npm run build:mp-weixin`，产物在 `miniapp/dist/build/mp-weixin`。
- [ ] 你：开发者工具里导入该目录，点「上传」，版本号 1.0.0。
- [ ] 你：后台把这个版本设为体验版，用手机走一遍主流程：首页 → 搜「遗」→ 字词详情 → 点出处 → 原文定位 → 收藏 → 生词本；再清掉小程序缓存重进，确认生词本还在。
- [ ] 你：提交审核。审核备注里写明「无需登录即可使用全部查询功能，登录为静默登录，仅用于保存生词本」。
- [ ] 你：审核通过后点发布。

## 五、上线后

- [ ] 数据库备份：`docker compose exec postgres pg_dump -U xueke xueke > backup.sql`，建议每天一次。
- [ ] 看日志：`docker compose logs -f api`。
- [ ] 更新内容：见《接口与数据设计》第 4 节。
